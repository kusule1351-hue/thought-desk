Questions

Is Thought Desk free?

Yes. It's free to download and use, and its code is open source under the GNU AGPL licence.

How can I support Thought Desk?

Thought Desk is made by one person, with help from contributors. You can sponsor it on GitHub, once or every month. The first goal is $1,000: the tools and app store fees for iPhone, iPad and Android versions, and a backend upgrade for sync, so your notes stay in step between your computer and your phone.

Where are my notes kept?

On your computer, in a folder you can choose in Settings → Storage. They're never uploaded. You can export them all as Markdown whenever you like.

Does it work without internet?

Yes, everything works offline. The app only goes online to check for a new version.

Is there a version for Mac or Linux?

Yes. Thought Desk runs on Windows 10 and 11, on macOS (Apple silicon and Intel), and on Linux, with a .deb for Ubuntu and Debian and an AppImage for other distributions. Export as PDF works only on Windows for now.

Windows says it "protected your PC". Is the installer safe?

The installer isn't code-signed yet, so Windows doesn't recognise it. Click More info, then Run anyway. If Smart App Control is on, it blocks unsigned apps outright; signed releases are on the way (see the code signing policy). On a Mac, Thought Desk is signed and checked by Apple, so it opens like any other app. The code is public, and every release is built from it on GitHub.

How do updates work?

Thought Desk checks for a new version when it starts and installs it with one click. Your notes stay as they are.

Can I bring my notes from Notion or Obsidian?

Paste Markdown and it keeps its headings, lists, code and math, and a database can import a CSV file. There's no one-click import from Notion yet.

Where can I get help?

Email support@thoughtdesk.org, or report a problem on GitHub.
